# Pomodo

Минималистичное Chrome-расширение с настраиваемыми Pomodoro-циклами, системными уведомлениями, цветным badge и локальным счётчиком завершённых сессий.

## Разработка

```bash
npm install
npm test
npm run build
```

## Установка в Chrome

1. Выполните `npm install` и `npm run build`.
2. Откройте `chrome://extensions`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку `dist`.

Все данные хранятся локально через `chrome.storage.local`. Расширение не запрашивает доступ к страницам и не отправляет данные в сеть.
